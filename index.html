Template voor embedded iframe-tool

Dit bestand is bedoeld als voorbeeld voor externe partijen die hun tool in een iframe laten embedden in de hoofdapplicatie. De communicatie met de parent-pagina verloopt uitsluitend via window.postMessage() met JSON-berichten.

Dit template laat zien hoe je:

  • toegestane origin-waarden controleert
  • alleen expliciet toegestane functies accepteert
  • JSON-berichten valideert
  • veilig terugpraat naar de parent
Berichten vanaf parent komen binnen:
  • Na kaart item onclick event (met sendToIframe() functionaliteit)
  • In dit frame uitgelezen onder window.addEventListener("message")
  • event bevat het onclick event
  • event.data bevat de aangeklikte itemgegevens
